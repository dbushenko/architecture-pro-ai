# Hugging Face RAG Bot с Online API

Это приложение представляет собой улучшенного RAG-бота (Retrieval-Augmented Generation), который использует векторный индекс из Task3 для поиска релевантной информации и генерации ответов с использованием онлайн-модели Qwen через API. Бот автоматически применяет методики Chain-of-Thought и Few-Shot Learning для улучшения качества ответов.

## Описание

Бот использует:
- Векторный индекс из Task3 (на базе модели all-MiniLM-L6-v2) для поиска релевантных документов
- Онлайн-модель (через OpenRouter API) для генерации осмысленных ответов
- Автоматическое применение методик улучшения качества ответов: Chain-of-Thought и Few-Shot Learning
- Структурированный подход к формированию осмысленных ответов на основе найденной информации

## Файлы проекта

- `rag_bot_qwen_api.py` - основной файл с реализацией RAG-бота с онлайн-генерацией
- `openrouter_creds.json` - файл с API-токеном для доступа к онлайн-модели
- `writetoken.txt` - файл с токеном API Hugging Face (для векторного хранилища)
- `README.md` - документация проекта
- `run_bot.sh` - скрипт для запуска RAG-бота

## Подготовка

Прежде чем запустить бота, вам нужно получить API-ключ от OpenRouter и сохранить его в файле `openrouter_creds.json` в формате:
```json
{
  "api_key": "ваш_openrouter_api_ключ"
}
```

## Запуск

Для запуска RAG-бота:

```bash
cd Task4
source ../.venv/bin/activate  # Активировать виртуальное окружение
python rag_bot_qwen_api.py
```

## Особенности

- Использует векторный индекс из Task3 для поиска релевантной информации
- Использует мощную онлайн-модель Qwen для генерации осмысленных ответов
- Автоматически применяет методики Chain-of-Thought и Few-Shot Learning для улучшения качества ответов
- Интерактивный режим для задания вопросов
- Структурированный подход к анализу и ответу на вопросы

## Методы анализа

Программа автоматически применяет оба метода:
1. **Chain-of-Thought**: Анализ вопроса по шагам с логическим выводом ответа
2. **Few-Shot Learning**: Использование примеров структуры ответов для формирования подходящего ответа
