# Векторный индекс для RAG-бота

## Описание
Этот проект создает векторный индекс на основе базы знаний для использования в RAG (Retrieval-Augmented Generation) боте.

## Модель эмбеддингов
- **Модель**: all-MiniLM-L6-v2
- **Ссылка**: https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2
- **Размер эмбеддингов**: 384

## База знаний
- **Источник**: `/../Task2/knowledge_base`
- **Формат**: `.txt` файлы с переименованными терминами (см. `../Task2/terms_map.json`)
- **Количество документов**: 33
- **Количество чанков после обработки**: 12167

## Параметры разделения текста
- **Размер чанка**: 500 символов
- **Перекрытие чанков**: 50 символов

## Векторная база данных
- **Тип**: FAISS (Facebook AI Similarity Search)
- **Формат хранения**: локальные файлы
- **Размещение индекса**: `./vector_store`

## Результат
Создан векторный индекс, содержащий 12167 текстовых чанков, который может использоваться для семантического поиска релевантной информации при обработке запросов пользователя.

## Тестирование
Индекс был протестирован с помощью различных запросов, и показал корректную работу:
- Запрос "Who is the main villain?" возвращает документы, связанные с персонажами-злодеями
- Запрос "Tell me about the spaceship technology" находит документы, описывающие космические технологии
- Запрос "What happened in the last battle?" находит документы, описывающие битвы

## Время генерации
- Время создания индекса зависит от объема базы знаний и производительности системы
- Для текущей базы из 33 документов процесс занимает несколько минут
